# X post entry — promote make your own bounty

The entry is a post on X by @vinzsenzo promoting make.fun's make-your-own-bounty launch:
https://x.com/vinzsenzo/status/2125440018001084784

`POST.json` holds that post's address. Running `main.ts` copies it from the
bot directory (`MAKEFUN_BOT_DIR`) into the output directory
(`MAKEFUN_OUTPUT_DIR`), byte for byte, for the house to read:

    mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
